# Prompt Heist (Hugging Face Space)

A 30-level browser game about prompt injection, built for Hacktoberfest Hack Day NITH GDG 2026 by Team Zero Spot.
The guards are **Gemma 4** (`gemma4:e2b`, Apache 2.0) running through Ollama **inside this Space, on CPU**, so replies
take longer than on a GPU. Everything in the game is fictional.

Source code, README and the 30 levels: https://github.com/rajat552/prompt-heist

The first visit after the Space has been asleep takes a few minutes while the model loads.
